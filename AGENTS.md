# Repository guidance

This repository publishes one portable Agent Skill. Keep the canonical skill at:

- .agents/skills/incredible-md3-in-gpt/SKILL.md

## Editing rules

- Keep the main skill concise and procedural. Put detailed knowledge in references and link to it from the skill.
- Keep advice specific to native mobile apps. Do not import web landing-page rules such as hover-only affordances, hero sections, or mandatory bento grids into native app guidance.
- Treat Material 3 as a design system foundation, not a mandate to use every default component or visual treatment.
- Treat FlClash as a case study. Do not copy its source code, assets, screenshots, or distinctive screens.
- Enforce the minimal-copy policy: no explanatory microcopy, repeated setting descriptions, decorative captions, or tiny filler text by default. Keep only text that helps identify, choose, act, understand a meaningful state, or recover from a problem.
- Attribute external projects and official documentation in references/research-sources.md.
- Do not claim that a UI was visually tested unless a running build was actually inspected.
- Keep the skill portable across Codex, Claude Code, Cursor, Gemini, and other Agent Skills-compatible tools.
